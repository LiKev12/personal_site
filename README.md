# personal_site

My personal website → **https://likev12.github.io/personal_site/**

A minimal static site — plain HTML/CSS/JS, no build step. A short intro, a few
projects, and interactive write-ups ("Jots"). Hosted free on GitHub Pages.

## Structure
- `index.html` — the entire site (styles + scripts inline, no dependencies)
- `Kevin_K_Li_Resume.pdf` — résumé, linked from the sidebar

## Local preview
Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
